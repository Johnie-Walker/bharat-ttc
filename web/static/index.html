      From one truck’s warning to a near-miss map

      Layer 1 protects the driver on the device. Every alert also leaves the vehicle as a tiny record, no video, so a fleet can see which road stretches are filling up with near-misses.

      Layer 2 scoring (next step)

      λ̂h = (α + Σk∈h wk sk e−λ(tnow−tk)) ÷ (β + Eh)

      Per H3 cell h: severity sk = the record’s DRAC, weighted up for vulnerable road users, decayed over time, shrunk toward the city average by fleet exposure Eh. Records above are in this format; the map itself is not part of this prototype.

      Path to deployment

      From the pitch deck
      1. Open release. Apache-2.0 code and an ONNX INT8 detector on dashcams fleets already install.
      2. 4–6 week shadow mode with a partner fleet: alerts logged, not spoken, to tune thresholds against a false-alert budget.
      3. Driver-facing A/B pilot: one short voice cue that names the side; measure alerts per hour, cut-in recall and near-miss maps.
